## 0. 适用范围与硬性前提

| 项 | 约定 |
|---|---|
| 宿主 | React 18 + Vite + **Tailwind 3.4.19 + HSL CSS 变量**（不升 v4）、Radix/shadcn 同源组件 |
| 图标 | `lucide-react`，**1.5px 描边、16–20px**，一律 `currentColor` |
| 图表 | `recharts`（不引入 Tremor）；表格 `@tanstack/react-table` |
| 字体 | **Inter Variable**（界面）+ **JetBrains Mono Variable**（数字/时间/ID），SIL OFL，Fontsource npm **自托管，禁止 CDN/外链** |
| 换肤 | CSS 变量 + `.agent-app` 作用域覆盖（不污染 Bisheng 全局，可灰度） |
| 外壳 | **自有外壳**：左侧 72px 窄导航 rail + 顶部 56px 页面头横条。不使用 Bisheng 的宽侧边栏 |

观感总开关（缺一条就退回"表格拼一拼"）：深色画布 `#0A0A0C`、卡片 `#141417`、1px 发丝描边、**几乎无投影**；字阶落差 ≈4×；数字全部等宽 + tabular-nums；每屏一个中等饱和强调色；语义色只做透明底药丸；内容区无渐变。

## 2. 字体与字阶

```css
font-family: 'Inter Variable', -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif;
.font-mono { font-family: 'JetBrains Mono Variable', ui-monospace, Menlo, monospace;
             font-variant-numeric: tabular-nums; }
```
中文跟随 Inter 后系统中文栈（PingFang/微软雅黑），**不许**为中文单设字体族造成两套基线。

### 2.1 字阶表（落差 ≈4×：40 → 10.5）

| 阶 | 字号/行高 | 字重 | 字距 | 等宽? | 场景 |
|---|---|---|---|---|---|
| display | 40/44 | 600 | -0.01em | ✅ + tnum | KPI 大数字 |
| h1 | 32/40 | 600 | -0.01em | ❌ | 页面标题、身份横幅姓名、审批标题 |
| h2 | 15/22 | 600 | 0 | ❌ | 卡片区块标题（"最近运行""职权"） |
| body | 14/20 | 400 | 0 | ❌ | 正文、表格首列姓名、理由文本 |
| body-2 | 13/18 | 400–500 | 0 | 视内容 | 表格单元、Tab、按钮、次要说明 |
| meta | 12/16 | 400 | 0 | ✅（数字部分） | 生效时间、来源、口径注 |
| micro | 10.5/14 | 600 | **+0.08em** | ❌ | 列头、KPI 指标名、分区标签（拉丁转大写；中文用微标签时**不大写、保留字距**） |

### 2.2 等宽使用范围（强制）

**一律用 JetBrains Mono + tabular-nums**：所有数字（含百分比、金额、计数）、所有时间、run_id / ap 单号 / 版本号 `v2`、耗时、token 数、预算进度比。**表格数字列右对齐**。ID/单号用 `12.5px`，其余数字按所属层级取号。姓名、岗位、理由、按钮文字一律 Inter。

## 3. 间距、圆角与容器层级

### 3.1 间距刻度（4 的倍数）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`

- 页面内容区左右 padding 32；卡片之间 gap **16**；卡片 padding **20**（KPI 卡 16）；卡内分区间 **16–20**；表格首末列水平 padding 20。
- 行高密度：表格行 **48–56**（列表页取 52）；抽屉/详情行内条目 12–16。

### 3.2 圆角两级（不许出现第三级）

| 级 | 值 | 用在 |
|---|---|---|
| 外卡 | **16**（允许区间 14–20） | 卡片、Drawer、弹层 |
| 内嵌 | **8–10** | 内嵌面板 10、按钮 8、输入框 8、段控件 8、图片/头像 10 |
| 药丸 | 999 | Badge、风险胶囊、待办计数（这是形状语义，不算第三级圆角刻度） |

### 3.3 容器层级规则（决定"什么时候用内嵌面板、什么时候只用一条线"）

最多两层：**卡 → 嵌面板**。禁止卡中卡再套卡。

| 场景 | 做法 |
|---|---|
| 需要成组的独立信息（KPI、表格、trace 单条、职权清单） | 外层 `--card` + 1px `--hairline`，**无投影（深色）/一层极浅投影（浅色）** |
| 卡内的次级区块（trace 展开的 JSON 明细、审批理由引用块、嵌在列表行的操作条） | `--surface` 底 + 圆角 10，**不加描边**（底色已足够）；需要更强区分时只允许 1px `--hairline` |
| 卡内只是分组 | **只用一条 hairline 水平线** + micro 标签，不起面板（如审批详情的分区、身份横幅下的元信息行） |
| 判断口诀 | "这块内容会被单独操作/单独滚动吗？" 会 → 嵌面板；只是读 → 一条线 |

## 4. 组件规格

### 4.1 外壳（自有，不用 Bisheng 侧边栏）
- **左 rail 72px**：右缘 1px hairline。logo 位 + 6 个导航项（总览/员工/审批/运行/审计/设置），每项 = 20px 图标 + 11px 标签，垂直间距 8，选中项 `--surface` 底圆角 10 + `--accent` 4px 圆点。审批项带待办计数小徽标（warning 药丸）。
- **顶部横条 56px**：左 = 面包屑（13px，当前页 foreground、上级 muted）；右 = ⌘K 搜索胶囊（260×32）、环境徽标（生产环境=neutral 药丸 + success 圆点）、头像。

### 4.2 页面头
`h1` 32px + 一行 13–14px `--muted-foreground` 说明（说"这页管什么"，不说实现）；右侧操作区：至多 1 个实心 + 1–2 个描边按钮，间距 8，与标题底对齐。详情页标题下允许 mono 12px 的元信息行（ID、动作原值）。

### 4.3 KPI 卡
宽 = 栅格 4 等分，gap 16。结构：micro 标签（10.5px 大写 +0.08em）→ display 数字 40px mono tnum → 口径注 meta 12px muted（**必须写清口径**，如"较上周 +2"「占月预算 38%」）。可选右下角 64px 离散方块迷你图。禁止在 KPI 卡里放图表动画。

### 4.4 列表表格（TanStack Table）
- 容器 = 一张卡，内边距 0，表头 sticky。
- 表头：micro 10.5px `--micro-foreground`，数字列表头也右对齐；行高 52；**只有水平 hairline**（每行下边线，末行无线），**无竖线、无斑马纹**。
- 单元格主行 14px（姓名）/13px 次行 12px meta。数字列 mono 右对齐。
- hover：`--hover` 底。**选中行：底色 `--accent-soft` + 四边 1px `--accent-border` 描边（首末格圆角 10），不是加粗、不是实色块**。
- 行操作：末列 ghost icon 按钮（chevron / more-horizontal），不做文字链。
- 底部：分页文字 mono 12px「显示 1–10，共 18」+ 左右 ghost 按钮。

### 4.5 身份横幅（员工详情头部）
一张卡：56px 头像（圆角 12，姓名首字）→ 右侧姓名 h1 32 + 状态 Badge → 元信息行 mono/meta 12：`v2 · 生效 11-06 10:12 · 负责人 陈诚`。右端操作区：实心（主操作，如"发布新版本"）+ 描边（暂停）+ ghost ⋯。卡内底部再加一条 hairline，其下放 4–6 个微型指标（工位、知识范围、日 token 上限…）：micro 标签 + mono 值，一行排开，**不再起嵌面板**。

### 4.6 Tabs
下划线式：13px/500，高 40，间距 24；选中 = `--foreground` + 2px `--accent` 下划线，未选 = `--muted-foreground`；整条 Tab 底部 1px hairline（下划线压在线上）。Tab 数 ≤5。带计数时用 mono 小字跟在标签后。

### 4.7 状态 Badge（药丸）
12px/500，padding `2px 10px`，圆角 999，左 6px 圆点（1px 同色描边光圈）。**永远 点 + 文字，不只靠颜色**。

| 状态 | 语义 | 深色示例 |
|---|---|---|
| active / completed / approved / 生产正常 | success 药丸 | 在岗 |
| onboarding / pending / running / 即将到期 | warning 药丸 | 入职中 · 待审批 · 运行中 |
| failed / rejected / 高风险 | danger 药丸 | 失败 · 已驳回 |
| draft / paused / archived / 低风险 | neutral 药丸 | 草稿 · 已暂停 · 已归档 |
| offboarding / interrupted | accent 药丸（低透明度底）或 neutral+说明 | 离职中 · 已中断 |

生命周期六态必须两两可辨：草稿=neutral 无点、暂停=neutral+斜杠图标、归档=neutral+mono「—」——用**形状+文字**，不是靠色相硬扛。

### 4.8 按钮（三级 + 危险软胶囊）
高 36（小 32），圆角 8，13px/500，图标 16（gap 8）。

| 级 | 样式 | 用途 |
|---|---|---|
| 实心 | 深：`--primary` 底 `--primary-foreground` 字（**白底黑字**）；浅：黑底白字 | 每屏 ≤1 个主操作 |
| 描边 | 透明底 + 1px `--border` + `--foreground` 字；hover `--hover` | 次要操作 |
| 幽灵 | 透明底 + `--muted-foreground`；hover `--hover` 变 `--foreground` | 行内、icon-only（hover 出 tooltip） |
| 危险 | `--danger-soft` 底 + `--danger` 字（**软红胶囊，禁止大红块**） | 驳回/移除/停用 |

禁用态 = 40% 透明度 + 禁止 cursor；同屏实心不超过 1 个；决策区按钮顺序：批准（实心）→ 要求修改（描边）→ 驳回（危险胶囊）。

### 4.9 空态
嵌面板（`--surface` 圆角 10）高 ≥120：居中 20px ghost 图标 → 一行 14px `--foreground`（说清"这里本来会有什么"）→ 一行 13px muted（下一步指引）→ 可选一个描边按钮。**禁止**只有一行灰字，禁止"暂无数据"了事（要写"近 7 天没有运行记录"）。

### 4.10 Drawer（右侧滑入，宽 520）
`--card` 底 + 左缘 1px hairline（深色无遮罩阴影；浅色 `--shadow`），遮罩 `--scrim`（**无 blur**）。结构：头部（标题 15px + ghost ×）→ 内部分区 micro 标签 + 一条线 → 底部操作条固定在底（描边 + 实心）。打开时页面主体不滚动，Esc / 点遮罩关闭。

### 4.11 Trace 时间线（Langfuse 式，本风格的灵魂组件）
- 每条 run 一张卡：头部 = 状态点 + mono run_id（截断+复制，见 4.12）+ 右侧 mono 耗时、mono 成本 + usage 徽标（`upstream`/`estimated`，图例在卡脚）。
- step 行高 36：左 24px 缩进/层，父子之间 1px 竖轨线 `--hairline`；每行 = 状态点（6px）+ step 名 13px + 右对齐 mono 耗时 12px（≥1s 一位小数）+ 成本药丸（有费用的 step 才显示）。
- 可展开 step：chevron-right 点击展开 `--surface` 明细面板（tokens 进出、首响时间、命中知识条目等 key/value，mono 值右对齐）。失败 step：danger 点 + danger-soft 行底 + 紧随一行 13px `--danger` 中文原因（人话，见 §5.5）。
- **禁止**：给时间线加动画、把每步画成柱状图（耗时条只允许步间相对比较的 1px 细条，默认不出现）。

### 4.12 复制 ID
`mono 12.5` 显示截断值（见 5.1），左侧透明 ghost 复制 icon 16，hover 才现形；点击 → 写入完整原值 → icon 变 check + tooltip「已复制」1.2s。`title` 属性挂完整 ID，键盘可聚焦。

### 4.13 筛选条
一行排开：段控件（状态 + mono 计数，`--surface` 底、选中段 `--card` 底 + hairline，圆角 8）→ Select chips（岗位/负责人/工位，描边小胶囊带 chevron）→ 搜索输入 240–280（`--surface` 底 + `--border`）。整条吸顶在表格卡上方，间距 8。**所有列表页共用这一条结构**，不许每页发明一套。

## 5. 文案与数字口径

### 5.1 ID 截断

### 5.2 时间

## 6. 无障碍

1. **对比度 AA**：正文/微标签 ≥4.5:1（表内 `--micro-foreground` 已按此取值）；大字（h1/display）≥3:1。
2. **状态不只靠颜色**：所有 Badge = 圆点 + 文字；生命周期同色相状态用形状区分（草稿无点/暂停带图标/归档带「—」）；风险等级除颜色外必带"低/中/高"字。
3. **发丝线不是信息载体**：`--hairline`（.08 alpha）仅作装饰；选中、错误、警示必须另有 accent-border / danger 文字 / 图标。
4. **Focus ring**：统一 `box-shadow: 0 0 0 2px var(--background), 0 0 0 4px var(--accent-border)`；tab 可达（表格行、trace step、复制按钮），focus 样式深浅两主题都在 `:focus-visible` 下验证（深色易吞 outline，已用 4px 环兜底）。
5. 图标按钮必须有 `aria-label`（「复制 run id」）；复制成功用 `aria-live="polite"` 播报；段控件用 `role="tablist"` 语义。
6. 动效：全站仅 hover/展开 120ms ease，无自动播放动画；尊重 `prefers-reduced-motion`（时长置 0）。

## V2.13 实现方最容易做走样的三处

1. **把 ChatPanel 做成自研聊天**。它是 iframe：控制台只给边框、头部、高度 512、右栏 400 和 `<1280` 降级；一旦有人试图用本设计系统的 token 去重绘 iframe 内部气泡，就会同时破坏 Bisheng 主题一致性并做出「假对话」。`在 Bisheng 中打开` 只能有一个动作定义。
2. **把「数据墨色」当「语义色」到处泼**。`--q-*`/`--heat-*`/`--chart-c` 一旦离开图形、进入按钮底、行底色或标题色，就退回大色块 banner；同时若去掉旁边的文字/数字标注，色盲与灰阶下整页信息直接消失（违反「不只靠颜色」）。
3. **HeatGrid / BlastRadius 的几何与字段映射被随手简化**。格子必须 28px＋2px 缝＋3px 圆角、小时轴每 3 格与格子严格对齐、焦点行加粗；爆炸半径的连线端点必须落在点上（节点盒子＝圆点，标签绝对定位），且每个节点带着真实 `grant_id`/动作键/域键——画成一团没有字段的装饰性脑图，这一屏就白做了。
