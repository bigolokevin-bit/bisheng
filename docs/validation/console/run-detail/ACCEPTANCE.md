# RUN-02 运行详情 · 实现侧摘要

- 路由：`/agent/runs/:id`，只读；设计源 `docs/product/console-v3/PRD-v0.3.md` §5.5
- 数据源：`GET /api/run-detail`（头部与摘要）、`GET /api/run-detail?events`（事件流）
- 权限：401 整页；403 与 404 走同一 forbidden 分支，同一文案与请求号，仅状态码不同
- 时间：事件发生/拉取时间显示北京时间 `YYYY-MM-DD HH:mm`，tooltip 保留完整 ISO；缺失 `—`
- 成本：`cost_ledger` 唯一源，原值不二次舍入，统一 `$` 前缀；无账目「未计费」，未知 `—`，不出现英文占位
- 状态：运行状态中文；耗时由起止时间推导，任一端缺失即 `—`
- 错误：人话标题/说明 + 请求编号（缺则「未提供」）+ 重试 + 返回列表；400 保留返回出口
- 事件流：时间正序、空态与错误态分离、支持展开 payload 与继续加载
- 关联：任务与审计仅在存在时渲染；缺失不占位
- 不可用：终止运行（无 terminate 端点与 grant 来源，标「不可用/权限未授」）；tokens（契约无 usage 字段，页面不渲染，不造假 0）
- 验证：`RunsDetail.test.tsx` 28 例通过；全车道 733 通过；构建 `build-q2c` 页面标记落在非 entry chunk
- 未测：真实 BFF 403/404/5xx 实态、375/768/1280/1440 与明主题视觉、E2E

## 实现侧复验（2026-11-18 晨）
- 错误屏与 403/404 卡去掉了 `HTTP <code>` 工程串，保留人话、请求编号（缺「未提供」）、重试与返回。
- 事件步骤详情去掉 `stepSeq` 字段名，只显示序号；事件时间与成本口径见核销表。
