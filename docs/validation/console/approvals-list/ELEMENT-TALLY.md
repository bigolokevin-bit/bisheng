## 本轮 Q2 修复

1. 移除列表页可见的 HTTP 码、`grant_escalation` / `permission` 等原始枚举与字段名。
2. 变更类型、风险、状态改中文；未知值降级为「其他变更 / —」，原值仅进 title。
3. 403 与 404 合并为同一张卡；请求号保留且可复制。
4. 空态区分「真实 0」与「计数仍 >0 但本页无可展示记录」，不再暗示全部处理完。
5. AP8 失败/缺键不再落成 0；倒计时 title 改为绝对北京时间，不再出现 `remainingSeconds=`。
6. 批量失败原因去掉 HTTP 码，保留人话原因与成功/失败计数。
7. 测试：`ApprovalsList.test.tsx` 28 项全过；全量 AgentConsoleV2 711 项全过。
