## 8. GAP 与裁决声明（施工纪律）

- `due_before` 仅单边；「已逾期」反向=客户端派生，控件不假装服务端双向范围。
- 排序：T5 无参数→**UI 不出现可点排序控件**；默认序需后端确认（CR-候选）。
- 多选状态合并的游标语义=待定策略（建议逐路第一页+明示），验收前 L0 拍板。
- KPI 聚合无 task-stats 端点=读侧聚合声明口径；趋势迷你图无源→点阵+「无趋势源」，禁假曲线。
- 字段名以 TASK.md snake_case 为准；camelCase=DTO 层；关联运行用 `source.run_id`。
- 参考屏示例数据不得当真实数据验收（§5）；颜色令牌不自创（§6）。
